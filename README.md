# My Resume Website

Personal resume website built with HTML and CSS for the Website Development midterm.

## Files
- `index.html` - the page
- `style.css` - all the styling
- `photo.jpg` - the profile photo in the header. To use a different photo, just replace this file with another one named `photo.jpg`.

## How to host it on GitHub Pages
1. Create a repository on GitHub (or open your existing resume repo).
2. Upload `index.html`, `style.css` and `photo.jpg` (Add file > Upload files), then Commit.
3. Go to Settings > Pages.
4. Under "Build and deployment", choose Deploy from a branch, pick `main` and `/ (root)`, Save.
5. Wait a minute, then open the link GitHub shows (https://YOUR-USERNAME.github.io/REPO-NAME/).
